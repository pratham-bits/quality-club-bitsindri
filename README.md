# Quality Club — BIT Sindri

React + Vite static website starter for Quality Club, BIT Sindri.

## Stack
- React
- Vite
- React Router
- Framer Motion
- Lucide React
- Plain CSS design system

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Content architecture

- `src/data/team.js` → replace placeholders with official team information.
- `src/data/events.js` → add actual events.
- `src/data/faqs.js` → update FAQs after club approval.
- `public/images/` → add official team/event/IFQM assets.

## Join Us

The Join Us buttons currently act as placeholders. Replace the `href="#"` in the relevant components with the official Google Form URL once available.

## Collaboration

Recommended branch naming:

- `feature/navbar-home`
- `feature/about-team`
- `feature/events-faq-contact`

Keep `main` protected and merge through pull requests.
